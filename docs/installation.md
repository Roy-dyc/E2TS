# Installation

## Stable release

To install E2TS, run this command in your terminal:

```sh
uv add E2TS
```

Or if you prefer to use `pip`:

```sh
pip install E2TS
```

## From source

The source files for E2TS can be downloaded from the [Github repo](https://github.com/Roy-dyc/E2TS).

You can either clone the public repository:

```sh
git clone https://github.com/Roy-dyc/E2TS
```

Or download the [tarball](https://github.com/Roy-dyc/E2TS/tarball/main):

```sh
curl -OJL https://github.com/Roy-dyc/E2TS/tarball/main
```

Once you have a copy of the source, you can install it with:

```sh
cd E2TS
uv sync
```
